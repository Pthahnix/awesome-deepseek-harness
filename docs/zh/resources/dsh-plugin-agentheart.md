## 详细介绍

基于 AgentHeart 概念开发的 DSH（DeepSeek Harness）插件。它为 AI agent 注入周期性"心跳"唤醒机制，让 agent 不再被动等待指令，而是按固定节律主动"醒来"——维护记忆、感知环境、按兴趣探索，再决定是否开口。结合 AgentHeart 本身"让 AI 拥有持续存在感"的理念，这款插件将"心跳"从概念落地为可安装、可配置的 DSH 插件，为 agent 赋予真正的自主性与主动性。
