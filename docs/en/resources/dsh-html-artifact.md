## About

HTML 实时渲染插件：模型通过专门的 artifact 工具创建/修补 HTML 文档，GUI 在沙箱 iframe 里实时渲染。核心区别：模型打 patch（old_string/new_string，和文件 edit 工具同一套语义），而不是每次重发整个 HTML —— 只传增量，预览原地更新。
